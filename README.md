# Дизайн без дизайнера

Материалы урока для nFactorial: как получать от AI-агентов нормальный дизайн, если вы не дизайнер.

| Файл | Что внутри |
|------|------------|
| [`prompt-kit.md`](prompt-kit.md) | Раздатка: промпты, агент-критик, чеклист сгенерённого дизайна, блок для `CLAUDE.md` |
| [`design-without-designer.pdf`](design-without-designer.pdf) | Слайды урока |
| [`design-without-designer.key`](design-without-designer.key) | Исходник слайдов (Keynote) |

## Как пользоваться

1. Откройте `prompt-kit.md` — промпты копируются и работают как есть.
2. Раздел «Блок для CLAUDE.md / AGENTS.md» вставьте в свой проект целиком.
3. Прогоняйте результат через чеклист из раздела 7 перед тем, как показывать кому-то.
